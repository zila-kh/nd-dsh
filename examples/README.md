# Fullstack Todo Application (In-Memory RAM Storage)

This repository contains `todo`, a zero-database fullstack todo application featuring a native Node.js REST API server (RAM array storage) and a React + TypeScript + Vite frontend.

## Quick Start

### Installation

```bash
cd todo
npm install
```

### Run Server

```bash
cd todo
npm run server
```
*Backend server runs on port 3001 (`http://127.0.0.1:3001`).*

### Run Client UI

```bash
cd todo
npm run dev
```
*Frontend dev server runs on port 5173 (`http://127.0.0.1:5173`).*

### Run Integration Tests

```bash
cd todo
npm test
```

For detailed feature list, API documentation, and architecture breakdown, see [`todo/README.md`](./todo/README.md).
